## 🔬 Flagship Project — Sentinel-AI

> **An Autonomous 13-Layer National Cyber Defense System**  
> *Targeting IEEE Access publication*

Sentinel-AI is my Final Year Project — a state-of-the-art Intrusion Detection System (IDS) built with 13 specialized defense layers plus a full XAI (Explainable AI) module. Trained and validated on **CICIDS-2017**, with cross-dataset generalization tested on CIC-IDS-2018 and UNSW-NB15.

| Layer | Module | Highlight |
|-------|--------|-----------|
| L1 | Supervised Ensemble (LightGBM + Transformer + BiLSTM) | Ensemble F1 = 0.99999 on unseen Friday data |
| L2 | Unsupervised Ensemble (PCA+IsoForest, β-VAE, RealNVP) | Covariate shift documented as IEEE finding |
| L3 | GAN Adversarial Robustness (WGAN-GP) | Botnet F1 = 0.9184 via L1+L2+L3 voting |
| L4 | PPO Reinforcement Learning Agent | F1 = 0.9988 · 28,191 flows/sec · 0% FP |
| L5 | Federated Learning (FedAvg + DP, ε=1.0) | 4 datasets · 5 non-IID clients · 30 rounds |
| L6 | Zero Trust Engine | Recall = 1.000 · 8 micro-segments |
| L7 | APT / Temporal Detection (Transformer) | F1 = 0.9997 · C&C beaconing at 60.1s period |
| L8 | Honeypot & Deception Layer | Precision = 1.0 · 200 attackers fingerprinted |
| L9 | Quantum-Safe Cryptography | Kyber-1024 + Dilithium5 · NIST Level 5 |
| L10 | SCADA / ICS Protection | F1 = 0.852 · 6 industrial protocols |
| L11 | MITRE ATT&CK Attribution | F1 = 0.940 · 6 APT groups |
| L12 | Encrypted Traffic Analysis (JA3 + CNN-LSTM) | F1 = 1.0 · 8 malware fingerprints |
| L13 | Graph Neural Network (GAT) | Binary F1 = 0.953 · Star topology detection |
| XAI | SHAP + LIME + Counterfactual + IG + RL | Fully autonomous: Sense · Detect · Act · Heal |
